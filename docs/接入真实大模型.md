# 乐颜 · 接入真实大模型（DeepSeek / 豆包 / 通义）

架构:前端 `ai.ts` →(llm 模式)→ **代理后端**(藏 key)→ OpenAI 兼容大模型。
任何失败(无代理/无 key/超时)自动回退规则模拟,**永不白屏**。前端**绝不持有 key**。

```
浏览器 ai.ts ──▶ proxy/llm-proxy.mjs (localhost:8787, 藏key) ──▶ DeepSeek/豆包/通义
```

## 启用步骤(3 步)

### 1. 配置代理的 key(服务端,key 只在这里)
```bash
cd leyan
copy proxy\.env.example proxy\.env      # Windows；macOS/Linux 用 cp
```
编辑 `proxy/.env`,三选一填入(默认 DeepSeek):
```
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-pro
LLM_API_KEY=sk-你的真实key
```
> 豆包:`https://ark.cn-beijing.volces.com/api/v3` + 接入点ID;
> 通义:`https://dashscope.aliyuncs.com/compatible-mode/v1` + `qwen-plus`。

### 2. 开启前端 llm 模式
```bash
copy .env.example .env.local            # 里面已是 VITE_AI_BACKEND=llm
```

### 3. 同时启动代理和前端
```bash
node proxy/llm-proxy.mjs     # 终端1：代理(看到 hasKey=true 即正常)
npm run dev                  # 终端2：前端
```
打开 http://localhost:3000,进"悄悄话"发一句话,回复就是**真实模型**生成的了。

## 验证
- 代理健康:浏览器开 `http://localhost:8787/api/health` → `hasKey:true`。
- 悄悄话/智能助手/数据报告等所有 AI 功能都会走真实模型。
- 把 `proxy/.env` 的 key 删掉重启 → 自动回退规则模拟,功能照常(只是回复变模板)。

## 安全
- key 只在 `proxy/.env`(已 gitignore),浏览器/仓库都没有。
- 上线公网:把 `proxy/.env` 的 `CORS_ORIGIN` 改成你的域名;代理部署在服务器,不要暴露 key。
- 生产正路仍是**苍穹 Agent**(服务端托管 + RAG + 工具调用),代理是无苍穹环境时的等价替代。
