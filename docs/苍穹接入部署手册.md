# 乐颜 · 金蝶苍穹接入与部署手册

> 目标：把前端从「本地 localStorage 持久化」切到「苍穹 + PostgreSQL」生产数据库。
> 现在没有苍穹环境也能本地跑（自动用本地持久化）；拿到环境后按本手册即可上线。

## 0. 现状（无需苍穹即可运行）
- 数据访问层 `app/kwc/leyan/api.ts` 默认 `BACKEND='local'`：数据存浏览器 localStorage，**刷新不丢**。
- 登录态存 sessionStorage，**刷新保持登录**。
- 一旦检测到苍穹运行时（`window.__KWC_PLATFORM__`），`BACKEND` 自动变 `'cosmic'`，改调控制器。

## 1. 准备苍穹环境（你来做，需金蝶账号）
1. 注册/登录金蝶云苍穹开发者门户，开通一个**开发环境**（拿到环境 URL、数据中心）。
2. 新建一个**应用**（记下应用编码，如 `kdtest_leyan`）——前端 `.kwp/.kws` 里的 `<app>` 要与之一致。
3. 新建一个 **OpenAPI 第三方应用**，拿到 `client_id` / `client_secret` / 集成用户名（**敏感，自己保管，别发给任何人**）。

## 2. 建领域模型（→ 自动生成 PostgreSQL 表）
按 `docs/数据库与领域模型规格.md`，在苍穹「领域模型设计器」逐个创建 `ly_student`、`ly_mood_log`、
`ly_treehole`、`ly_diary`、`ly_alert`、`ly_talk_record`、`ly_config` …… 保存后平台自动在 PostgreSQL 建表。

## 3. 连接环境并授权（在 leyan 目录）
```bash
# 创建并连接 dev 环境（URL 换成你的苍穹开发环境地址）
kd env create dev --url https://<你的苍穹环境>:1026/<数据中心>/

# OpenAPI 授权（交互式，逐项填你的实际配置——secret 你自己输入）
kd env auth openapi
#   √ 选择数据中心
#   √ client_id
#   √ client_secret   ← 敏感，自己输入
#   √ 用户名（如 IERP）
```

## 4. 部署组件、页面、控制器
```bash
npm run build:frontend          # 构建 KWC 组件
npm run build:controller -e dev # 构建 Kingscript 控制器
kd project deploy               # 推送 组件+页面+控制器 元数据到苍穹
```
部署后，控制器接口形如 `https://<环境>/ierp/kapi/app/DiaryController/list`。

## 5. 切换前端到苍穹数据源
两种方式任选：
- **自动**：把前端打包进苍穹页面运行时，`window.__KWC_PLATFORM__` 存在即自动切 `cosmic`。
- **手动**：把 `api.ts` 顶部 `BACKEND` 改成 `'cosmic'`，并设 `window.__KWC_COSMIC_BASE__` 为你的环境域名。

## 6. 验证
- 登录后写一条日记 → 应写入 `ly_diary`（PostgreSQL），换浏览器/设备也能看到（不再只在本地）。
- 树洞抱抱 → `ly_treehole_hug` 一人一条、可取消。
- 预警推进 → `ly_alert.status` 变更并记录闭环时间。

## 角色与认证（生产）
- 三端登录（`/`、`/teacher`、`/admin`）生产环境应改为**苍穹身份认证**（账号体系 + 角色权限），
  前端不再持有任何账号密码；当前前端校验仅用于无环境时的演示。
- 教师/管理对学生个案的可见范围由苍穹 RBAC + 预警授权控制，遵循最小必要原则。

---
**安全提醒**：`client_secret`、集成用户密码等凭据请你本人在终端输入，不要写进代码仓库或发给他人。
