# 乐颜 · 数据库与领域模型规格（苍穹建模 → PostgreSQL）

> 在金蝶苍穹「领域模型设计器」按本规格建模，平台会自动在 **PostgreSQL** 生成对应表结构。
> 前端通过 `app/kwc/leyan/api.ts` 调用控制器读写这些表（见 `app/ks/controller/`）。
> 字段类型对照：文本=varchar/text，整数=int/bigint，小数=decimal，布尔=boolean，时间=timestamp，枚举=单选下拉。

## 通用约定
- 每个实体含平台标准字段：`id`(主键)、`createTime`、`modifyTime`、`creator`、`org`(组织)。
- 学生一律以**脱敏编号**关联，不存真实姓名/学号（合规）。
- 枚举值统一：心情 `joy/love/calm/low/anxious/sad`；关注等级 `high/mid/low/none`；预警状态 `new/processing/resolved`。

---

## 1. ly_student 学生（脱敏）
| 字段 | 名称 | 类型 | 说明 |
|---|---|---|---|
| number | 编号 | varchar(32) | 脱敏唯一编号，如 2026-A1 |
| college | 学院 | varchar(64) | |
| className | 班级 | varchar(64) | |
| grade | 年级 | varchar(16) | 研一/研二… |
| riskLevel | 关注等级 | 枚举 | high/mid/low/none |
| tags | 标签 | varchar(255) | 逗号分隔，如"睡眠紊乱,学业压力" |
| lastActive | 最近活跃 | timestamp | |

## 2. ly_mood_log 心情打卡
| 字段 | 名称 | 类型 | 说明 |
|---|---|---|---|
| student | 学生 | 基础资料(ly_student) | 关联 |
| logDate | 日期 | date | |
| mood | 心情 | 枚举 | joy/love/calm/low/anxious/sad |
| note | 备注 | text | 可空 |
| anonymous | 是否匿名 | boolean | |

> 索引：(student, logDate)。情绪花园、暖心首页、成长曲线、预警检测均读此表。

## 3. ly_chat_session / ly_chat_msg 悄悄话
**会话 ly_chat_session**：student、startTime、lastMood(枚举)、crisisFlag(boolean 危机标记)。
**消息 ly_chat_msg**：session(关联)、role(me/warm)、content(text)、detectedMood(枚举)、createTime。
> crisisFlag=true 时由工作流触发加急预警。

## 4. ly_treehole 树洞帖子 + ly_treehole_hug 抱抱
**ly_treehole**：content(text)、tag(varchar)、hugs(int)、sameFeel(int)、anonymous(boolean=true)、createTime。
**ly_treehole_hug**：post(关联)、user(关联)、createTime。唯一索引(post,user) 保证一人一抱、可取消。

## 5. ly_diary 小确幸日记
| 字段 | 名称 | 类型 |
|---|---|---|
| student | 学生 | 关联 |
| content | 内容 | text |
| emoji | 表情 | varchar(8) |
| createTime | 时间 | timestamp |

## 6. ly_artwork 疗愈画作
student、prompt(text 提示词)、palette(varchar 色板)、bright(int)、warm(int)、interpret(text AI解读)、createTime。

## 7. ly_alert 预警事件
| 字段 | 名称 | 类型 | 说明 |
|---|---|---|---|
| alertNo | 预警号 | varchar(32) | AL-2061 |
| student | 学生 | 关联 | |
| className | 班级 | varchar(64) | |
| level | 等级 | 枚举 | high/mid/low/none |
| reason | 触发原因 | text | |
| status | 状态 | 枚举 | new/processing/resolved |
| owner | 负责人 | 用户 | |
| triggerTime | 触发时间 | timestamp | |
| closeTime | 闭环时间 | timestamp | 可空 |

> 闭环率、响应时长由本表统计；驾驶舱/预警中心读此表。

## 8. ly_talk_record 谈心记录
teacher(用户)、student(关联)、talkDate(date)、topic(varchar)、summary(text)、followUp(text)、done(boolean)。

## 9. ly_class 班级
className(varchar)、counselor(用户 辅导员)、psychTemp(int 心理温度)、treeGrowth(int 心理树成长值)、studentCount(int)。

## 10. ly_resource 心理资源
title(varchar)、type(枚举 音频/图文/活动/课程)、content(text/附件)、usage(int 使用量)、status(枚举 上架/草稿)、emoji。

## 11. ly_activity 陪伴活动
title、description(text)、type、joined(int)、total(int)、days(int)、createTime。

## 12. ly_config 系统配置（单例/按组织）
riskThresholdHigh(int)、riskThresholdMid(int)、notifyApp/notifySms/notifyEmail(boolean)、anonymousDefault(boolean)、nightMode(varchar)。
