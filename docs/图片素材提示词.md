## 放置与生效

1. 用上面提示词在 chatgpt-image-2.0 生成图片；
2. **导出为对应文件名**（logo/hero/empty 记得**透明 PNG**，背景图为 JPG）；
3. 放入 `leyan/app/kwc/static/img/`；
4. 刷新 `http://localhost:3000`，logo、首页插画、背景、空状态会自动替换为真图。

> 若某张暂时不生成，留空即可——对应位置会继续用内置 SVG/emoji 兜底，不会报错。
