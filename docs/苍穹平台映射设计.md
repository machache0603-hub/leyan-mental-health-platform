# 乐颜 · 金蝶 AI 苍穹平台映射设计说明书

> 配套《系统设计说明书》核心章节 —— 说明本作品如何以**金蝶 AI 苍穹**为开发底座，
> 将前端 KWC 组件、低代码领域模型、Agent 智能体三层有机串联，形成完整业务闭环。

---

## 1. 总体架构

```
┌──────────────────────────────────────────────────────────────┐
│  前端表现层  ·  KWC 前端框架（React + TypeScript）              │
│  学生端 10 · 教师端 9 · 管理端 6 = 25 个 KWC 页面/组件          │
└───────────────┬──────────────────────────────────────────────┘
                │  苍穹页面元数据(.kwp) + 控制器(.kws/Kingscript)
┌───────────────▼──────────────────────────────────────────────┐
│  服务/逻辑层  ·  苍穹低代码 PaaS                                │
│  领域模型(BOS) · 业务表单 · 服务模型 · 工作流 · 报表 · 集成     │
└───────────────┬──────────────────────────────────────────────┘
                │  统一 AI 网关
┌───────────────▼──────────────────────────────────────────────┐
│  AI 智能体层  ·  苍穹 Agent 平台                                │
│  RAG 知识库 · 任务流编排 · 工具调用(Tool Calling) · 多步推理    │
│  多模态大模型：DeepSeek V4 / 豆包 / 通义千问（平台统一接入）    │
└───────────────┬──────────────────────────────────────────────┘
                │
        PostgreSQL（苍穹托管）· 云原生微服务
```

- **开发语言**：服务端 Java（苍穹插件） + Kingscript（KWC 控制器）；前端 TypeScript。
- **数据库**：PostgreSQL（苍穹平台托管）。
- **大模型**：通过苍穹 AI 网关统一接入，应用层不直连，便于切换与合规。

## 2. 领域模型设计（低代码 BOS 建模）

| 实体编码 | 名称 | 关键字段 | 说明 |
|---|---|---|---|
| `ly_student` | 学生（脱敏） | 编号、学院、班级、年级、关注等级 | 仅存脱敏编号，不含真实姓名/学号 |
| `ly_mood_log` | 心情打卡 | 学生、日期、心情(枚举)、备注、是否匿名 | 情绪花园/首页心情的数据源 |
| `ly_chat_session` | 悄悄话会话 | 学生、消息、识别情绪、危机标记 | 对接 Agent，触发预警 |
| `ly_treehole` | 树洞帖子 | 内容、标签、抱抱数、同感数、匿名 | 匿名社区 |
| `ly_diary` | 小确幸日记 | 学生、日期、内容、表情 | 个人记录 |
| `ly_artwork` | 疗愈画作 | 学生、提示词、色板参数、AI 解读 | 多模态生成 |
| `ly_alert` | 预警事件 | 学生、等级、原因、状态、负责人、时间线 | 预警闭环主表 |
| `ly_talk_record` | 谈心记录 | 教师、学生、主题、摘要、跟进计划、状态 | 教师干预记录 |
| `ly_class` | 班级 | 名称、辅导员、心理温度、成长值 | 班级晴雨表/心理树 |
| `ly_resource` | 心理资源 | 标题、类型、内容、使用量、上下架 | 资源中心/电台/小站 |
| `ly_activity` | 陪伴活动 | 标题、类型、参与人、周期 | 训练营/打卡 |
| `ly_score` | 成绩 | 学生、学期、课程、本次/上次成绩、变化、排名 | 成绩导入/成绩→心情预测 |
| `ly_teacher_performance` | 教师绩效 | 教师、学院、周期、预警闭环率、谈心次数、心情改善分、学业陪伴分、综合分 | 学院教师绩效看板 |
| `ly_config` | 系统配置 | 预警阈值、通知渠道、权限策略 | 管理端全局设置 |

**枚举**：心情 `joy/love/calm/low/anxious/sad`；关注等级 `high/mid/low/none`；预警状态 `new/processing/resolved`。

**权限模型**：基于苍穹 RBAC——学生仅见本人数据；教师在「授权班级 + 预警范围」内见脱敏个案；管理员见全校聚合视图。遵循最小必要原则。

## 3. 业务流程闭环（工作流服务）

**心理预警闭环**（核心业务闭环，对应「预警管理中心」）：

```
情绪数据采集(心情打卡/悄悄话/量表)
   → Agent 情绪识别 + 规则引擎(连续低落≥阈值)
   → 自动生成 ly_alert(状态=new)
   → 苍穹工作流派单给辅导员(站内/短信/邮件通知)
   → 教师受理→谈心(ly_talk_record)→必要时转介心理中心
   → 标记闭环(状态=resolved) + 回访跟进
   → 数据沉淀至驾驶舱(闭环率/响应时长)
```

危机等级（识别到自伤倾向关键词）走**加急通道**：即时通知 + 强制人工介入 + 热线引导。

## 4. Agent 智能体设计（苍穹 Agent 平台）

| Agent | 能力 | 苍穹平台技术 | 对应前端功能 |
|---|---|---|---|
| **小暖陪伴 Agent** | 共情对话、情绪识别、危机检测、放松练习推荐 | 情感计算 + 多轮对话 + 工具调用(写心情/转介) | ② 悄悄话、全站悬浮球 |
| **学业关怀 Agent** | 谈心话题/评语/家校话术/班级建议生成 | RAG(心理辅导知识库) + 多步推理 | ⑭ 教师智能助手 |
| **校园洞察 Agent** | 全校态势分析、预测性分析、行动建议 | 数据分析工具调用 + 报告生成 | ⑲ 驾驶舱、㉓ 数据报告 |
| **疗愈创作 Agent** | 文生图(水彩)、画作情绪解读 | 多模态大模型 | ④ 艺术疗愈画室 |
| **成绩关怀 Agent** | 成绩导入分析、成绩→心情预测、学业风险预警、教师绩效评估 | 数据分析工具调用 + 多步推理 | ⑲ 成绩导入（教师端） |

**RAG 知识库构建**：导入《大学生心理健康手册》、危机干预 SOP、谈心技巧、教育部心理健康政策等语料 → 苍穹向量化入库 → 对话/生成时检索增强，保证专业性与合规性。

**工具调用(Tool Calling)** 示例：小暖 Agent 可调用
`createMoodLog()`、`pushRelaxExercise()`、`escalateToCounselor()`、`queryCampusHotline()` 等苍穹服务模型注册的工具。

> 前端 `app/kwc/leyan/ai.ts` 中的接口签名（`detectEmotion`/`smallTalk`/`genTalkTopics`/`genReport`/`predictMoodByGrade`/`genTeacherPerformance` 等）即为对接上述 Agent 的**契约**，演示环境用规则模拟，生产环境替换为苍穹 Agent 调用，前端无需改动。

## 5. KWC 前端 ↔ 苍穹 部署映射

| 前端工程文件 | 苍穹产物 | 说明 |
|---|---|---|
| `app/kwc/leyan/features/*.tsx` 中各功能组件 | KWC 组件元数据(.kwc) | `kd project create X --type kwc` |
| `app/pages/*.page-meta.kwp` | 苍穹页面 | 组件实例编排，挂载到苍穹应用 |
| `app/ks/controller/*.ts/.kws` | Kingscript 控制器 | 前端数据接口，部署到苍穹 |
| 部署 | `kd project deploy` → 苍穹环境 | OpenAPI 授权后推送元数据 |

演示工程为可独立运行的 KWC SPA（`npm run dev`），与苍穹部署形态共用同一套组件代码。

## 6. 数据可视化与决策支持

- 驾驶舱：环形(心理温度)、折线(预警趋势)、学院热度排名 —— 对应苍穹**报表/图表**能力。
- 预测性分析：心情天气预报、压力峰值预测 —— Agent 数据能力 + 历史 `ly_mood_log`。
- 异常检测：情绪骤降、深夜活跃 + 负面关键词 —— 规则引擎 + Agent 协同。

---

## 7. 合规与隐私

1. 全部为**模拟数据**，无任何真实学生个人信息（学生以脱敏编号标识）。
2. 数据脱敏存储；教师按授权范围访问；管理端仅见聚合数据。
3. AI 输出经知识库约束，危机场景强制转人工，内置心理热线兜底。
