# 乐颜 · AI 原生智慧校园心理健康关爱平台

> 第十五届软件杯 A6 赛题 · 基于金蝶 AI 苍穹 + KWC 前端框架
> 「一盏永远亮着的小夜灯，不是冰冷的工具，是温暖的陪伴。」

## 一、项目简介

面向高校校园心理健康场景的 AI 原生应用，以吉祥物「小暖」（拟人化小夜灯，灯光随情绪变色）
为情感纽带，覆盖**学生 / 教师 / 管理**三端共 **25 个功能**，构建从情绪采集→识别→陪伴→预警→
干预→闭环的完整业务闭环。

## 二、技术栈

- 前端：KWC 前端框架（React 19 + TypeScript），暖色调设计系统、夜间自动暗色
- 低代码：金蝶 AI 苍穹（领域模型 / 表单 / 工作流 / 报表 / 服务模型）
- AI：苍穹 Agent 平台（RAG 知识库 / 工具调用 / 多步推理）+ DeepSeek/豆包/通义千问
- 数据库：PostgreSQL（苍穹托管）；服务端 Java + Kingscript

## 三、功能总览

**学生端(10)**：① 暖心首页 ② 悄悄话 ③ 情绪花园 ④ 艺术疗愈画室 ⑤ 树洞广场
⑥ 成长空间 ⑦ 暖心小站 ⑧ 小确幸日记 ⑨ 心灵电台 ⑩ 治愈工坊

**教师端(8)**：⑪ 教师工作台 ⑫ 班级晴雨表 ⑬ 学生档案 ⑭ 智能助手
⑮ 谈心记录本 ⑯ 陪伴训练营 ⑰ 班级心理树 ⑱ 教师休憩站

**管理端(6)**：⑲ 校园心理驾驶舱 ⑳ 心理温度地图 ㉑ 预警管理中心
㉒ 资源中心 ㉓ 数据报告 ㉔ 系统配置

## 四、AI 亮点

- **小暖陪伴 Agent**：实时情绪识别（灯光变色）、共情对话、危机检测、放松练习自动推送
- **教师智能助手**：谈心切入点 / 三风格评语 / 家校话术 / 班级建议一键生成（页面无"AI"字样）
- **校园洞察 Agent**：全校态势多步推理、预测性分析（心情天气预报）、周期报告自动生成
- **疗愈创作 Agent**：文生水彩画 + 画作情绪解读（多模态）

## 五、本地运行（演示）

```bash
cd leyan
npm install
npm run dev        # 打开 http://localhost:3000
```

入口 `app/kwc/main.tsx` 挂载完整 SPA；左上角可切换学生/教师/管理三端，右上角 ☀️/🌙 切换日夜。

## 六、目录结构

```
app/kwc/leyan/
├── theme.css            暖色调设计系统（含暗色/夜间）
├── data.ts              模拟数据层（全脱敏，无真实个人信息）
├── ai.ts                AI 能力服务（对接苍穹 Agent 的契约，演示用模拟实现）
├── store.tsx            全局状态（角色/心情/主题/悬浮球）
├── ui.tsx / charts.tsx  共享组件 / SVG 可视化
├── App.tsx              应用外壳（导航/布局/小暖悬浮球）
└── features/            student.tsx · teacher.tsx · admin.tsx（25 功能）
app/ks/controller/       Kingscript 后端控制器示例（心情打卡 API）
docs/苍穹平台映射设计.md   领域模型 / Agent / 工作流 / 部署映射
```

## 七、合规声明

全部数据为模拟数据，学生以脱敏编号标识，不含任何真实学生个人信息。
数据脱敏存储，教师按授权范围访问，遵循最小必要原则。
