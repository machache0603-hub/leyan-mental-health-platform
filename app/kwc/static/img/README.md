# 乐颜 · 图片素材目录

把用 chatgpt-image-2.0 生成的图片放到这里（文件名必须一致），刷新页面即生效。
未放图时，界面自动回退到内置 SVG/emoji，不会报错。

dev server 通过 `/img/<文件名>` 访问本目录（不使用任何外链网址）。

| 文件名 | 用途 | 尺寸 | 背景 |
|---|---|---|---|
| `xiaonuan-logo.png` | 品牌 logo / 悬浮球 / 站点图标 | 512×512 | 透明 |
| `xiaonuan-hero.png` | 首页暖心签 / 悄悄话头像（全身小暖） | 800×800 | 透明 |
| `xiaonuan-empty.png` | 空状态插画 | 600×600 | 透明 |
| `bg-ambient-light.jpg` | 日间背景氛围图 | 1920×1200 | 不透明 |
| `bg-ambient-night.jpg` | 夜间背景氛围图 | 1920×1200 | 不透明 |
| `login-bg.jpg` | 登录页左侧品牌区背景 | 1200×1500 | 不透明 |
| `garden-banner.jpg` | 情绪花园顶部横幅 | 1600×500 | 不透明 |

具体生成提示词见 `docs/图片素材提示词.md`。
